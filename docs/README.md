# Documentacion de DevMarket

Este directorio contiene la documentacion funcional y tecnica del proyecto hasta la fecha.

## Archivos

- `01-objetivo-y-alcance.md`: define que se busca desarrollar y que incluye esta version.
- `02-estado-actual-del-proyecto.md`: inventario del estado real del codigo, fortalezas y puntos pendientes.
- `03-arquitectura-y-flujo.md`: explica como esta organizada la aplicacion y como fluye la informacion.
- `04-roadmap-recomendado.md`: plan por fases para evolucionar el proyecto de forma ordenada.

## Lectura recomendada

1. Empezar por el objetivo y alcance.
2. Revisar estado actual para entender que ya funciona.
3. Continuar con arquitectura para entender el codigo.
4. Seguir el roadmap para implementar mejoras.
