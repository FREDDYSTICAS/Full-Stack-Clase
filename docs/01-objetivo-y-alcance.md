# Objetivo y Alcance del Proyecto

## Objetivo principal

Desarrollar una aplicacion web tipo e-commerce llamada DevMarket para practicar un flujo Frontend completo con React.

La meta no es solo mostrar pantallas, sino construir un flujo real de compra:

- navegacion por rutas
- visualizacion de productos
- agregado al carrito
- resumen de compra
- confirmacion final

## Alcance actual

En el estado actual del proyecto, el alcance implementado es:

- SPA con React y Vite.
- Estilos con Tailwind CSS.
- Navegacion principal con React Router.
- Pantalla de productos con datos consumidos desde una API externa (Fake Store API).
- Carrito de compras con modal y flujo basico de checkout.
- Footer con informacion de contacto y enlaces.

## Alcance esperado a corto plazo

Para convertir este proyecto en una version mas completa y mantenible, se recomienda incluir:

- manejo de carga y errores en peticiones de productos
- calculo de totales considerando cantidades
- mejoras de accesibilidad en modal y navegacion
- limpieza de archivos no utilizados
- documentacion funcional y tecnica (este directorio)

## Publico objetivo de aprendizaje

Proyecto ideal para practicar:

- estado y props en React
- arquitectura por componentes
- enrutamiento en SPA
- consumo de APIs
- buenas practicas de UI y mantenibilidad
